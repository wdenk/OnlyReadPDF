# Installation Guide (Windows and macOS)

This app runs locally in your browser and does not need a server.

## macOS

1. Download the project ZIP from [GitHub](https://github.com/wdenk/OnlyReadPDF) using `Code` -> `Download ZIP`.
2. Open your `Downloads` folder and unzip the file.
3. Open the unzipped folder, then open `index.html`.
4. If macOS asks which app to use, choose your browser (Safari, Chrome, or Firefox).
5. Use `Open` in the toolbar or drag a PDF into the app.

## Windows

1. Download the project ZIP from [GitHub](https://github.com/wdenk/OnlyReadPDF) using `Code` -> `Download ZIP`.
2. In `Downloads`, right-click the ZIP and choose `Extract All...`.
3. Open the extracted folder and double-click `index.html`.
4. If Windows asks, choose your browser (Edge, Chrome, or Firefox).
5. Use `Open` in the toolbar or drag a PDF into the app.

## Tips

- Zoom with toolbar buttons or hold `Ctrl` and use the mouse wheel.
- Search from the top-right search field, then use `Prev`/`Next`.
- The app works offline after download.

# Simple PDF Reader

Minimal browser PDF reader with:

- scrolling through all pages
- zoom in/out/reset
- text search with real in-page term highlighting and previous/next match navigation
- drag-and-drop PDF open
- Ctrl + mouse wheel zoom
- keyboard shortcuts: `x` (next), `y` (previous)
- hold `Ctrl (STRG)` to show shortcut popup

## Run

No local server is required.

Open `/Users/jol/workspace/onlyreadPDF/index.html` directly in your browser.

## Installation

- End-user setup steps for macOS and Windows: `/Users/jol/workspace/onlyreadPDF/INSTALLATION.md`

## Notes
